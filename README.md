# VK Moderation Bot (для Bot-Host + Удаленная БД)

## 📁 Содержимое архива:
- `schema.sql` — Дамп таблицы для импорта на ваш сервер MySQL (в phpMyAdmin).
- `config.py` — Файл конфигурации для токена ВК и реквизитов подключения к базе данных.
- `database.py` — Модуль асинхронной работы с MySQL.
- `bot.py` — Главный файл логики бота и команд модерации.
- `requirements.txt` — Список библиотек Python.

## 🚀 Инструкция по запуску:
1. Загрузите `schema.sql` в базу данных на вашем удаленном сервере (через phpMyAdmin).
2. Заполните `config.py` своими данными (Токен группы ВК, Host, Login, Password, DB Name).
3. Загрузите архив на **Bot-Host** и установите зависимости: `pip install -r requirements.txt`.
4. Запустите `bot.py`.
5. Выдайте боту **Права Администратора** в беседе ВКонтакте.
