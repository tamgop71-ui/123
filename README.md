# VK Moderation Bot (8 уровней доступа + СУПЕР-ДОСТУП + Экзамен)

## 📁 Содержимое:
1. `schema.sql` — структуры таблиц для базы `whg118037_`.
2. `config.py` — параметры подключения к MySQL (127.0.0.1) и VK токен.
3. `database.py` — модуль работы с БД.
4. `questions.json` — вопросы для экзаменов и викторин (перенесены из PHP-версии).
5. `bot.py` — главный исполняемый скрипт бота.

## 🚀 Запуск:
1. Импортируйте `schema.sql` в phpMyAdmin базы `whg118037_`.
2. Замените `123456789` в `config.py` в поле `SUPER_ADMIN_IDS` на ваш реальный VK ID.
3. Запустите `pip install -r requirements.txt`.
4. Запустите `bot.py`.
