# VK Moderation Bot (8 уровней доступа + Супер-Админ)

## 📁 Файлы в архиве:
1. `schema.sql` — База данных MySQL. Импортируйте через phpMyAdmin в базу `whg118037_`.
2. `config.py` — Токен VK и параметры подключения к БД.
3. `database.py` — Модуль взаимодействия с MySQL.
4. `bot.py` — Движок бота с обработкой команд всех 8 уровней и супер-доступа.
5. `requirements.txt` — Зависимости.

## 👑 Система Доступа:
- **Уровень 0:** Обычный пользователь (`/help`, `/id`, `/stats`, `/top`, `/rep` и др.)
- **Уровни 1..7:** Администраторы по возрастанию привилегий.
- **Супер-Доступ (`/sdev`):** Специальный флаг `is_super = 1`. Выдается ТОЛЬКО Владельцем (ID из `SUPER_ADMIN_IDS` в `config.py`). Обходит абсолютно все проверки и может выполнять любые команды.

## 🚀 Запуск на Bot-Host:
1. Импортируйте `schema.sql` в базу данных.
2. Откройте `config.py` и пропишите ваш личный VK ID в переменную `SUPER_ADMIN_IDS = [ВАШ_VK_ID]`.
3. Загрузите файлы архива на хостинг и выполните `pip install -r requirements.txt`.
4. Запустите `bot.py` и выдайте боту **Права Администратора** в беседе VK.
